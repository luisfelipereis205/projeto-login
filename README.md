# Projeto de Login e Cadastro de Usuários

Desenvolvi uma aplicação web para praticar e demonstrar a criação de um sistema de autenticação de usuários, utilizando **HTML, CSS e JavaScript** no desenvolvimento da interface e **Node.js** no servidor.

O projeto conta com uma interface visual personalizada, uma área de cadastro de usuários, uma tela de login e um dashboard para acesso e visualização após a autenticação.

Para simular o funcionamento de um sistema real, utilizei um servidor local (`server.js`) com o objetivo de implementar a comunicação entre o front-end e o back-end, além de explorar o armazenamento de dados em um banco de dados local.

### Funcionalidades
- **Cadastro de usuários:** interface para preenchimento e registro de novos usuários.
- **Tela de login:** área para autenticação com as credenciais cadastradas.
- **Dashboard:** painel de acesso após o login, com uma interface organizada para apresentar informações ao usuário.
- **Servidor local:** utilização do Node.js para gerenciar as requisições da aplicação.
- **Banco de dados local:** armazenamento de dados para praticar operações de cadastro e autenticação.
- **Interface visual:** exploração de cores, elementos gráficos, organização dos campos e experiência de navegação.

### Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Node.js
- Servidor local (`server.js`)
- Banco de dados local para fins de estudo

### Objetivo do projeto

O objetivo foi consolidar meus conhecimentos em desenvolvimento web, explorando a integração entre front-end e back-end e compreendendo, na prática, como funcionam os processos de cadastro, autenticação e acesso a áreas restritas de uma aplicação.
